# Oracle PL/SQL Triggers

This folder contains Oracle PL/SQL Trigger programs and examples.

## Topics Covered
- BEFORE Trigger
- AFTER Trigger
- Row-Level Trigger
- Statement-Level Trigger
- INSERT Trigger
- UPDATE Trigger
- DELETE Trigger
- INSTEAD OF Trigger
- Trigger with WHEN Clause
- Trigger Examples on Tables
- Trigger using :NEW and :OLD
- Trigger with RAISE_APPLICATION_ERROR

## Purpose
These examples are created for learning Oracle PL/SQL triggers and interview preparation.

## Requirements
- Oracle Database
- SQL*Plus / SQL Developer

## Folder Structure
```
TRIGGERS
│── before_trigger.sql
│── after_trigger.sql
│── row_level_trigger.sql
│── statement_level_trigger.sql
│── instead_of_trigger.sql
│── trigger_examples.sql
```
