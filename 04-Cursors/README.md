# Cursors

## Overview
This folder contains Oracle PL/SQL cursor programs, including implicit and explicit cursors, cursor attributes, parameterized cursors, and practical examples.

## Topics Covered
- Implicit Cursors
- Explicit Cursors
- Cursor Attributes
- Parameterized Cursors
- FOR Loop Cursors
- Nested Cursors
- Cursor with Records
- Practical Examples
- Interview Questions

## Learning Objectives
- Understand the purpose of cursors.
- Learn how to declare, open, fetch, and close cursors.
- Work with cursor attributes and parameterized cursors.
- Implement real-world cursor-based programs.
